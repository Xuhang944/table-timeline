# 表格时间线

把表格按时间线排布并预演的**表格视图**插件（`tableview` 类型，面板内视图切换）。启用后，打开任意 `.atb` 表格，工具条「视图」下拉会出现「时间线」选项。

> **宿主要求：Atelyx 0.4.3 及以上**（插件包格式：`package.json` + 入口默认导出 `apply(ctx)`）。

## 功能

- **字段驱动卡片**：取第一个 `duration` 字段决定卡片宽度（60px/秒，最短 120px）与播放时长；无该字段 → 等宽卡片 + 固定 3s/行。
- **图片缩略图/大图**：取第一个 `image` 字段供卡片缩略图与预览大图；无图镜头显示首个 `text` 字段摘要文字卡片。
- **点击卡片跳选**：与表格视图 `selectedRowId` 联动（协作时远端选中行同样显示用户色边框）。
- **预演**：大图预览 + 控制条（播放/暂停/停止、当前时间/总时长）+ 刻度尺 + 播放头（rAF），播放中当前卡片自动滚入视野，播完自动停止、可重播。

## 安装与启用

1. 内置市场搜索「表格时间线」安装，或手动放到 `app_data_dir/plugins/com.atelyx.table-timeline/`。
2. 设置 → 插件 → 启用「表格时间线」。
3. 打开一个 `.atb` 表格，工具条「视图」下拉选择「时间线」即可切换视图。

## 权限说明

- `table`：读取当前打开的表格行/字段/图片与选中行（仅读取 + 跳选，不做任何内容修改）。

## 数据通道

本插件使用插件平台的 `ctx` API：

- `ctx.table.snapshot()` + `table:changed` 事件 — 当前表格数据快照（行/字段/选中行/协作选中行用户色）。
- `ctx.table.selectRow(rowId)` — 跳选行（与表格视图联动）。
- `ctx.table.resolveImage(entry)` — 表格图片条目 → dataURL。
- `ctx.slots.registerTableView(...)` — 注册表格编辑器内视图。
